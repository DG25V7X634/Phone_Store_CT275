PHONE STORE CT275 - GOI CHAY NHANH
=================================

1. Giai nen toan bo ZIP vao mot thu muc tren o E:.
2. Dam bao dich vu MySQL80 dang Running.
3. Nhan dup chuot vao CHAY_WEBSITE.bat.
4. Lan dau, nhap mat khau MySQL cua tai khoan root khi cua so PowerShell hoi.
   Khi go mat khau se khong hien ky tu; go xong nhan Enter.
5. Chuong trinh tu kiem tra va tao bo sung bang order_items neu thieu,
   sau do tu mo Chrome tai http://127.0.0.1:8000/.
6. Giu cua so den dang mo khi su dung website. Dong cua so hoac Ctrl+C se dung web.

GHI CHU:
- Khong can sua code va khong can tu tao file .env.
- Mat khau duoc luu trong file .env tren may nay de lan sau khong phai nhap lai.
- Khong gui file .env cho nguoi khac va khong dua len GitHub.
- Bo chay nay giu nguyen du lieu san pham/khach hang/don hang hien co.
- Neu port 8000 dang duoc dung, dong cua so CMD cu dang chay PHP truoc khi chay lai.
- Yeu cau PHP 8.2+ co PDO MySQL va dich vu MySQL80.
