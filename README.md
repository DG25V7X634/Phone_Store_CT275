## Cấu hình
Sao chép `.env.example` thành `.env`, nhập mật khẩu MySQL của máy vào `DB_PASSWORD`, sau đó chạy máy chủ PHP tích hợp trong thư mục `public`:

```bat
php -S 127.0.0.1:8000
```

Mở `http://127.0.0.1:8000/index.php`.
